# コピforカルステップ + カルテ連携 (CLIUS / M3デジカル)

カルステップ（診療録音 → SOAP 変換ソフト）が書き出す **Google スプレッドシートの
セル内容** を、**CLIUS** や **M3デジカル** の主訴・所見欄へ **ワンクリックで挿入**
する Chrome 拡張機能です。

元の「コピforカルステップ」は *H2 セル → クリップボードにコピー* まででしたが、
この拡張ではさらに **カルテ画面の入力欄へ直接挿入** まで行えます。
（従来どおりクリップボードへのコピーも残しています）

---

## 主な機能

- 📋 **クリップボードにコピー** … 従来機能（指定シートのセル → クリップボード）
- 🩺 **カルテに挿入** … 指定シートのセル内容を、開いているカルテの入力欄へ直接挿入
- 🎯 **対象欄の登録** … カルテ画面で挿入先の欄をクリックして記憶（サイトごと）
- 🧩 **SOAP 分割挿入（任意）** … `S) … O) … A) … P) …` を解析し、S/O/A/P 個別の欄へ振り分け
- ⌨️ **ショートカット** … `Alt+Shift+K`（挿入） / `Alt+Shift+C`（コピー）
- 🌐 CLIUS / M3デジカル に限らず、**どのカルテ Web 画面でも動作**（activeTab 方式）

---

## インストール（開発者モードでの読み込み）

1. このリポジトリをダウンロード / clone する。
2. Chrome で `chrome://extensions/` を開く。
3. 右上の **デベロッパーモード** をオンにする。
4. **パッケージ化されていない拡張機能を読み込む** をクリックし、このフォルダ
   （`manifest.json` がある場所）を選択する。

> アイコンを作り直す場合: `python3 tools/make_icons.py`

---

## 初期設定

拡張機能アイコンを右クリック →「オプション」、または初回インストール時に
自動で開く設定画面で以下を設定します。

### 1. 取得元
- **Google スプレッドシートから取得（推奨）**
  - カルステップが SOAP を書き出すシートの **URL または ID** を入力。
  - **取得するセル**（既定 `H2`）を指定。
  - シートは **共有 → 「リンクを知っている全員（閲覧者）」** にしてください。
    （OAuth を使わず gviz API で読み取るため、閲覧共有が必要です）
  - URL 内の `gid=...` で対象タブ（シート）を指定できます。
  - **取得テスト** ボタンで内容を確認できます。
- **クリップボードから取得**
  - カルステップが既にコピーした内容を、そのまま挿入に使います。
    （シートの共有設定が不要なぶん手軽ですが、コピー忘れに注意）

### 2. 挿入方法
- **置き換え**（欄を上書き）/ **追記**（末尾に追加）
- **SOAP を S/O/A/P に分けて挿入**（任意）

---

## 使い方

1. カルステップで診療内容を録音し、SOAP をスプレッドシートに書き出す。
2. CLIUS / M3デジカル でカルテを開く。
3. 拡張機能アイコンをクリック → **「カルテに挿入」**。

### 挿入先の欄を登録する（初回のみ推奨）

挿入先の欄は、次の優先順で決まります。

1. **登録済みの欄**（サイトごとに記憶）
2. **カーソルが置かれている欄**
3. **自動検出**（「主訴」「所見」などのラベルや大きなテキスト欄を推定）

より確実にするため、初回はカルテ画面で
**拡張アイコン →「対象欄を選択」** をクリックし、挿入したい欄をクリックして
登録してください。登録内容はサイト（オリジン）ごとに保存されます。

SOAP 分割をオンにしている場合は、ポップアップに **全文 / S / O / A / P** の
選択ボタンが並ぶので、それぞれの欄を登録できます。

## CLIUS / M3デジカル について

- どちらもブラウザで動作するクラウド型電子カルテのため、本拡張の
  **activeTab 方式**（アイコン操作時にその場のタブへ注入）で動作します。
  特定ドメインを manifest に固定していないので、URL 変更にも比較的強い作りです。
- 画面は React 等で作られていることが多いため、値を直接書き換えるだけでは
  アプリ側に変更が伝わりません。本拡張は
  **ネイティブ setter + `input`/`change` イベント発火** で書き込み、
  contenteditable 欄では `execCommand('insertText')` を用いることで、
  アプリに変更を認識させます。
- それでも反映されない特殊な入力欄がある場合は、
  **「追記」モード** や **「対象欄を選択」での明示登録** をお試しください。

> 注意: 各サービスの DOM 構造は変更されることがあります。挿入できなくなった
> 場合は「対象欄を選択」で登録し直してください。医療情報を扱うため、
> **挿入後は必ず内容をご確認のうえ保存** してください。

## ショートカット

| 操作 | 既定キー |
|------|----------|
| カルテに挿入 | `Alt+Shift+K` |
| クリップボードにコピー | `Alt+Shift+C` |

変更は `chrome://extensions/shortcuts` から行えます。

---

## 権限について

| 権限 | 用途 |
|------|------|
| `storage` | 設定・挿入先セレクタの保存 |
| `activeTab` / `scripting` | アイコン操作時に、開いているカルテ画面へ挿入処理を注入 |
| `clipboardWrite` / `clipboardRead` | クリップボードへのコピー / からの取得 |
| `host_permissions: docs.google.com` | シートのセル内容を読み取り |
| `optional_host_permissions: https://*/*` | 任意のカルテ画面での挿入（activeTab で都度許可） |

常時全サイトを監視するコンテンツスクリプトは登録していません。挿入処理は
**ユーザーがアイコン/ショートカットを操作した時だけ** 実行されます。

## ファイル構成

```
manifest.json          … 拡張機能定義 (Manifest V3)
src/
  background.js        … サービスワーカー（ショートカット処理）
  popup.html/js/css    … ツールバーのポップアップUI
  options.html/js/css  … 設定画面
  content/emr.js       … カルテ画面へ注入（挿入・対象欄選択）
  lib/
    sheets.js          … Googleスプレッドシート セル取得（gviz CSV）
    actions.js         … 取得・注入・保存などの共通処理
icons/                 … アイコン
tools/make_icons.py    … アイコン生成スクリプト
```
