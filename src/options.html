カルステップ → カルテ連携 設定

カルステップが書き出す Google スプレッドシートの内容を、CLIUS / M3デジカル の主訴・所見欄へ挿入します。

1. 取得元

シートは「共有 → リンクを知っている全員（閲覧者）」にしてください。 URL の gid でシート（タブ）を指定できます。

既定は H2。


          

        

      


      

        
2. 挿入方法

        

          
          
        

        

          
          

            オンにすると、本文中の S) … O) … A) … P) … を解析し、
            サイトごとに登録した S/O/A/P 各欄へ振り分けます（各欄の登録はポップアップから）。
            解析できない場合は全文を1欄に挿入します。
          

        

      


      

        
3. 挿入先（サイト別）

        

          挿入先の欄は、カルテ画面を開いた状態で拡張機能アイコン →「対象欄を選択」から登録します。
          未登録の場合はカーソル位置の欄、または自動検出した欄に挿入します。
        

        

      


      

        
使い方

        
    
          
  1. カルステップで診療内容を録音し、SOAP をスプレッドシートに書き出す。
    2. 
          
  2. CLIUS / M3デジカル でカルテを開く。
    3. 
          
  3. 拡張機能アイコンをクリック →「カルテに挿入」。（初回は「対象欄を選択」で欄を登録）
    4. 
          
  4. ショートカット: Alt+Shift+K 挿入 / Alt+Shift+C コピー
    5. 
        

        

          ショートカットは chrome://extensions/shortcuts で変更できます。
